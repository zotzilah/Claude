# Project Biro

A wishlist app inspired by the year-2000 high-street catalogue. Kids (and couples) wobbly-circle what they want in a catalogue made for them. Parents, family and guests claim and buy the items through a simple web link.

- **[Product brief](docs/PRODUCT_BRIEF.md)**: the source of truth for vision, features, tech approach and roadmap
- **[Clickable mockup](prototype/catalogue-mockup.html)**: catalogue, Kid Mode, the order slip and the Giver link

First release focus: **kids' Christmas lists**.
